# ACR-003 — Promote the Extension Stack Boundary

- ACR-ID: `ACR-003`
- Status: `APPROVED`
- Requested by: Chief Architect (via WORK-014)
- Decided by: Chief Architect
- Decision date: 2026-08-26
- Affected Architecture Version: `IAAS-DOM-ARCH-3` (FROZEN)
- New Architecture Version: `IAAS-DOM-ARCH-4` (FROZEN)
- Affected Requirements: `DOM-P04` (Extension + ExtensionRegistry + ExtensionRuntime)
- Affected Work Items: `WORK-014`, `WORK-015`

## Decision

**APPROVED.** ACR-003 promotes the Extension Stack boundary into `IAAS-DOM-ARCH-4`. The V4 architecture is now FROZEN. DOM-P04 is promoted out of FUTURE/OPEN/RESEARCH by this approved architecture transition.

The approved V4 contract includes Extension, ExtensionRegistry, ExtensionRuntime, and ExtensionProvenance boundaries; capability/resource-limit precedence; lifecycle authority and transition semantics; Extension↔Transform separation; tenant isolation; and the required anti-dependencies. Sandbox technology, Marketplace, SDK, cryptographic mechanism, packaging, pricing/settlement, economic attribution, and Fragmentation/Reassembly remain OPEN/FUTURE as specified by V4.

## Governance Effect

- `IAAS-DOM-ARCH-3` remains an immutable historical architecture version.
- `IAAS-DOM-ARCH-4` is the current canonical domain architecture.
- `DOM-P04` is superseded by `DOM-018..DOM-022` under V4.
- No production implementation is authorized by this approval alone.
- Extension implementation must proceed through subsequent bounded Work Items and independent Architect Review.

## Archived Architectural Record

The original ACR-003 proposal and WORK-014 evidence remain part of the historical decision record. This approval records the authoritative state transition only.
